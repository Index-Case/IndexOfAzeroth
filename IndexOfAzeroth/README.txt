HOW TO INSTALL THE INDEX
========================

1. Unpack the zip

   Right-click IndexOfAzeroth.zip and choose Extract All. Pick any folder
   you like. The zip unpacks to one folder, IndexOfAzeroth. That folder
   is the Index, and everything the Index needs stays inside it.

2. Start the Index

   Open the IndexOfAzeroth folder and double-click Start the Index.
   Windows may ask whether you really want to run it, because it comes
   from the internet and isn't signed. Choose Run.

3. The first start

   The Index opens in its own window and finds your World of Warcraft:
   Forever folder by itself.

   The Index then downloads its data, a few gigabytes, and shows the
   progress in its window. The map opens when the download is done.

   The Index puts its addon into the game's AddOns folder while the game
   is closed. If the game is running, the addon goes in once you close
   the game. The addon shows in the game at its next start.

   After that, start the Index the same way each time. The Index checks
   for a new version at every start and installs small updates by
   itself.


HOW TO REMOVE THE INDEX
=======================

   Double-click Uninstall the Index in the IndexOfAzeroth folder.
   The notes the Index keeps about your characters are set aside first.
